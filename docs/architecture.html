3 · Inside one research agent (create_agent)

builtThe model picks a tool, reads the result and repeats. It stops when it answers without a tool call. Middleware enforces the limits.

flowchart TB
  IN(["topic + date window
(+ feedback on a retry)"]) --> M
  M{{"model node
decides the next step
Nemotron (free) → Claude Haiku fallback"}}
  M -- "tool call" --> TN["tools node"]
  TN --> T1["web_search(query)
Anthropic search via Haiku"]
  TN --> T2["fetch_page(url)
free; only URLs it has seen"]
  TN --> T3["check_already_sent(url)
long-term memory"]
  TN --> T4["save_finding(item)
rejects: page not fetched, quote not on page,
date not on page, outside window"]
  T1 & T2 & T3 & T4 -- "result back to the model" --> M
  M -- "no tool call = done" --> OUT(["findings → fact_check"])
  G["guard rails (middleware)
model-call limit · tool-call limits
repeated-call loop detector · retries"] -.-> M
